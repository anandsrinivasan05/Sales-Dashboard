# 📊 Sales Dashboard - Power BI Project

## Overview

This project is an interactive Sales Dashboard developed in Power BI to analyze sales performance, profitability, customer metrics, and product trends. The dashboard enables stakeholders to monitor key business metrics and make data-driven decisions.

## Tools Used

* Power BI
* Power Query
* DAX
* Excel

## Key Performance Indicators (KPIs)

* Total Sales: 9.48M
* Total Profit: 1.09M
* Total Orders: 25K
* Total Quantity Sold: 95K
* Total Customers: 2K
* Average Order Value: 379
* Profit Margin: 11.50%

## Dashboard Features

* Monthly Sales Trend Analysis
* Top 5 Sales by Region
* Category-wise Sales Distribution
* Sub-Category Performance Analysis
* Interactive Slicers for:

  * Year
  * Region
  * Category
  * State
  * Quarter
  * Segment

## Key Insights

* Technology generated the highest sales contribution (39.5%).
* Central region recorded the highest sales revenue (2.07M).
* Sales showed strong growth in the final months of the year.
* Phones, Copiers, Chairs, and Bookcases were the top-performing sub-categories.
* The dashboard helps identify high-performing products, categories, and regions.
